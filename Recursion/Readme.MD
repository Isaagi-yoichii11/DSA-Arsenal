# Recursion — DSA Practice

This repository contains my recursion practice problems as I build a deeper understanding of problem-solving patterns in DSA.

My goal is to understand **why** a recursive approach works—not just memorize code or solutions.

## Learning Approach

For each problem, I aim to:

1. Understand the problem and explain it in my own words.
2. Start with a brute-force or recursive approach.
3. Identify the choices available at each step.
4. Define the base case carefully.
5. Write the recursive relation.
6. Dry-run the code on a small example.
7. Analyze time and space complexity.
8. Revisit the problem later and solve it without looking at the solution.
